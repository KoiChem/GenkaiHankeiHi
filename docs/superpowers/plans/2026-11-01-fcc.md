# FCC preview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Publish a separate FCC.html with accurate FCC and curved interstitial spaces while preserving index.html.
**Architecture:** Copy the existing app shell and original three modes into FCC.html. Add pure geometry/state helpers and an FCC view controller, sharing the existing renderer and cameras.
**Tech Stack:** Static HTML/CSS/JavaScript, existing Three.js r128, Node built-in tests.
**Spec:** docs/superpowers/specs/2026-11-01-fcc-design.md

## Global Constraints
- index.html unchanged; no build system or new runtime dependencies.
- All requested void sites, exact maximal radii, globally continuous ABC classification.
- Atom visibility never changes computed voids; clipping and comparison share base cube and scale.
- New controls have visible gaps; no unnecessary model labels.

## Review Focus
- Rays through hidden foreground atoms must still reach visible/hidden targets by intended priority.
- Triple taps cannot transiently invoke double hide; drag/pinch/longpress cannot invoke taps.
- Boundary sites and their neighbors remain geometrically correct in single-cell view.
- Crystal switches preserve both legacy and FCC settings.
- Comparison uses viewport-local picking coordinates and synchronized projection/zoom.
